# UpNow Spaces

Clean Spaces vertical project for the UpNow marketplace and provider workspace.

## Customer flow
Home → Spaces → Filters → Listings → Listing Detail → Channels

## Provider flow
Provider onboarding → Leads → Demand → Communications / Channels → Calendar → Settings

## Included
- Customer marketplace: `Home.html`, `Search.html`, `Listing.html`
- Customer assets: `css/`, `js/`, `img/`
- Provider workspace: Demand, Leads, Communications, Calendar and Settings
